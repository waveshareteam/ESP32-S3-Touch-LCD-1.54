# Waveshare ESP32-S3-Touch-LCD-1.54

[中文](README_ZH.md)

The ESP32-S3-Touch-LCD-1.54 is a compact, high-performance development board built around the ESP32-S3R8 (dual-core Xtensa LX7 @ 240 MHz, 8 MB PSRAM, 16 MB Flash) with 2.4 GHz Wi-Fi and Bluetooth 5 LE. It integrates a 1.54-inch 240 × 240 capacitive touch LCD, an audio module (ES8311 + ES7210), a QMI8658 six-axis IMU, an RTC, a TF card slot, USB Type-C, and a battery interface, making it suitable for LVGL GUI, voice interaction, wearable devices, and other IoT applications.

## Repository Structure

This repository provides sample programs and factory firmware for the ESP32-S3-Touch-LCD-1.54 and ESP32-S3-LCD-1.54.

```text
.
├── examples/        # Sample programs for ESP-IDF and Arduino
├── Firmware/        # Pre-built factory and example firmware (.bin)
└── assets/          # Images used in documentation
```
